Двухуровневая система

Уровень 1 — задача-обсуждение (R!): фиксирует обращение клиента, фотографии, переговоры с бригадой. Создаётся МОП/МОСом сразу при обращении — аналог тикета поддержки.

Уровень 2 — рабочие задачи: производство, постпечать, монтаж (любая комбинация) — создаются конструктором после решения по тикету. Без них задача-обсуждение не закрывается.

Бизнес-процесс: ID рекламации

При запуске система проверяет ID (например, R-00125): нет ID — создаются рекламация, запись в разделе и строка в Google Таблице; ID есть — задача привязывается к существующей, дубль записи не создаётся. В реестре всегда одна строка на рекламацию независимо от числа задач.

Реестр и роли

МОС вносит расходы (материал и иные статьи) и предварительных виновников; остальные данные тянутся из приложения Заказ. РО4 вносит финальные суммы удержания, утверждает запись и вручную распределяет доли по виновникам в таблице.

Автоматизации

РО4 добавляется наблюдателем во все задачи рекламаций · фильтр по тегу «рекламация» для задач обоих уровней · уведомления РО4 о незаполненных полях реестра через заданный период · после утверждения массив данных (ID, связанные задачи, виновники, суммы) уходит в зарплатную ведомость Google.
